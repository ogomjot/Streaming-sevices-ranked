About this project

Streaming Services Ranked is a personal project built to compare movie, TV, and music streaming platforms in one place, and to explore working with real APIs and authentication.

It started as a static HTML/CSS page listing a fixed set of services, and has since been upgraded to include live trending data (via TMDB), search and filtering, favoriting, and account sign-in (via Firebase).

Built and maintained by Agamjot Singh, an incoming B.Tech Computer Science student at GTBIT, New Delhi — as a hands-on way to learn front-end development, APIs, and deployment.
